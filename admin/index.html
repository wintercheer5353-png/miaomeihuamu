内容管理

以后可在这里进入管理页面，自行新增、排序、隐藏作品图片或视频。官网不保存密码，登录由 GitHub 负责。

使用 GitHub 登录管理

第一次使用

  1. 点上方按钮，使用官网仓库所属的 GitHub 账号登录。
  2. 首次会出现授权页面；确认只授权官网仓库。
  3. 选择 miaomeihuamu，进入“官网作品管理”。
  4. 新增一条，上传图片或 MP4 视频，打开“在官网展示”，保存。
  5. GitHub Pages 通常约 1–3 分钟更新。

发布前检查：只用已获公开授权的模特素材；不要上传带其他账号水印的视频。视频建议 MP4（H.264），单个尽量控制在 50MB 内。
